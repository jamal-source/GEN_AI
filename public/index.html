Konfigurasi lanjutan: hubungkan chatbot CS toko Anda dengan Langflow dan AstraDB untuk mengaktifkan pencarian pengetahuan dari katalog toko.

Langflow + AstraDB (Advanced) AstraDB Vector Store Auto-fallback ke Gemini Per-toko Isolasi Data
🛠️ Advanced Developer Settings (Langflow + AstraDB) Hanya untuk developer yang memahami arsitektur
⚠️ Zona Developer. Pengaturan ini tidak akan mengubah tampilan untuk pengguna biasa. Kredensial Langflow & AstraDB diproses oleh server (proxy `/api/*`), bukan di browser — token tidak pernah dikirim langsung dari halaman ini ke Langflow/AstraDB.

📖 Panduan Setup Langflow (3 Langkah)
1
Buka localhost:7860 (Langflow UI) → klik Import Flow → upload 2 file JSON dari folder langflow/ project ini.
2
Di setiap flow yang di-import, klik node AstraDB → isi Token dan API Endpoint kamu. Klik node Google Embeddings → isi Gemini API Key.
3
Salin Flow ID dari URL browser saat membuka tiap flow (format: /flow/XXXX-XXXX) → paste ke form di atas → klik Simpan & Aktifkan.
